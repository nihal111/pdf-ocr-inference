# Raw evaluator reports

These are new GPU timing runs from **2026-10-27**, measuring both pinned pipeline
modules at clean source revision `12f9cf6b67404c67bff68fb2e9790548b99c5aa7`. Both evaluations ran from a fresh
local clone, using its committed dataset and the existing runtime environments.

- `baseline.json`: `pipelines.baseline`, vLLM region batch 1.
- `optimized.json`: `pipelines.optimized`, the retained configuration.
- `comparison.json`: generated by the unchanged `eval/compare.py` from those runs.
- `baseline-env.json` and `optimized-env.json`: current environment, GPU identities,
  source revision and SHA-256 hashes of the measured Python sources.
- `provenance.json`: measurement paths, report hashes, settings and previous results.
- `launch-audit.json`: historical launch settings and the documentation corrections.

Both variants passed **all 30 calls**: five frozen PDFs / 20 pages, one warm-up
and five measured calls per PDF, concurrency 1, a 1,800-second timeout and minimum
embedding cosine 0.99. The baseline passed its existing OCR bytes, ordered chunk
IDs and embeddings. **No references were recaptured.** Neither evaluator code nor
correctness thresholds changed.

The fresh comparison gives **6.44× p50 speedup**,
**2.91× p95 speedup** and **3.69× throughput**.
Raw report latencies are in milliseconds; the table converts them to seconds.

| Metric | Baseline: previous → new | Optimized: previous → new |
| --- | ---: | ---: |
| p50 (s) | 15.083 → 15.102 | 2.229 → 2.344 |
| p95 (s) | 36.390 → 36.112 | 12.402 → 12.411 |
| Pages/minute | 12.193 → 12.266 | 46.122 → 45.235 |
| Time-to-first-result (s) | 30.666 → 41.399 | 272.506 → 131.344 |

Time-to-first-result is `cold_start.process_to_first_result_ms`: evaluator worker
startup plus the first warm-up, including client model loading and any compilation.
It excludes recognizer-server startup. These are single startup observations,
not warm-call percentiles or a controlled cold-cache benchmark.

The shipped dataset is `data/public-v3/manifest.json`, with paths relative to
`--root data/public-v3`. All five PDFs, references and metadata are committed;
all 13 files are below 1,000,000 bytes, and PDF page counts match the manifest.
W-9 and Census reference JSON was compacted without changing any parsed values.
That whitespace change changes the raw reference/dataset hashes, so historical
reports are retained as historical measurements and are not mixed with the new
pair by `compare.py`.

The launch audit found missing server environment exports and a missing optimized
`--isolate-compile-cache` option. README commands and both module docstrings now
match the recorded launches. Follow [the root README](../README.md#baseline-vs-optimized-with-the-evaluator)
to reproduce, exporting the four UUIDs in `baseline-env.json` and keeping the three
existing environments separate.

```bash
source .venv/bin/activate
python3 -m unittest discover -s eval/tests
python3 -m pytest tests/test_pipelines.py tests/test_pdf_contract.py tests/test_eval_cli.py tests/test_eval_compare.py tests/test_frozen_dataset.py
python3 eval/compare.py --baseline reports/baseline.json \
  --optimized reports/optimized.json --out reports/comparison.json
```
